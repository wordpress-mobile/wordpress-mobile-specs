## Repository Purpose

This repository contains specifications for how the WordPress mobile apps are supposed to work. It serves as the authoritative source for behavior specifications and requirements shared across both mobile platforms.

## Related Repositories

This specification repository is intended for use with two sibling repositories:

- **../WordPress-Android** - Android implementation (Kotlin/Java, Gradle)
  - GitHub: https://github.com/wordpress-mobile/WordPress-Android
- **../WordPress-iOS** - iOS implementation (Swift, Xcode)
  - GitHub: https://github.com/wordpress-mobile/WordPress-iOS

When working on specifications, consider how they apply to both platforms and their respective implementation constraints.
